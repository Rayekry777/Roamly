## 目标与金额契约

- 商家毛应收 = 顾客实付 + 平台补贴。
- 商家预计收入 = 商家毛应收 - 服务费。
- 服务费基数 = 商品售价 - 商家补贴，最小为 0。
- 既有 `platform_discount_amount` 由平台承担，财务语义为平台补贴。
- 核销时固化金额、费率和预计收入，后续规则变化不得改写历史快照。

## 实现

- 今日收银接口补充商品售价、商家补贴、平台补贴、顾客实付、服务费和预计收入。
- 核销确认账本按顾客实付加平台补贴确认商家毛应收，再单列服务费扣减。
- 已核销退款按同一毛应收口径冲回，服务费使用独立返还分录。
- 结算批次先进入 `PROCESSING`，每次 Mock 执行写入 `settlement_attempt`，成功后才变为 `SUCCEEDED`。
- 管理端重试创建新的幂等执行尝试并真正调用 Mock 执行，禁止直接把失败批次改成功。
- 商户端今日数据保持“团购数据 → 核销明细”，不增加外卖入口。
